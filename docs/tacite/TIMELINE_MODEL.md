# Tacite timeline model

## Product role

The timeline is the primary product surface.

Raw notes are input.
The timeline is the story.

## Timeline modes

### Daily mode

Newest first.

For daily use and recent capture.

Example:

Today

- Question for appointment
- Sleep worse
- Side effect note

Yesterday

- Took dose late
- Anxiety still high

### Review mode

Oldest first.

For reconstructing the story before an appointment.

Example:

1 May — Started ABC
3 May — Nausea appeared
7 May — Anxiety still high
14 May — Sleep improved

## Timeline card structure

Each card should include:

- date or approximate date
- event type
- short title
- compact summary
- source marker: raw / quick card / AI draft / edited
- episode link
- include/exclude from summary marker
- expand details
- edit action
- more menu

## Card interactions

Tap:

- expand details

Swipe right:

- add to summary / mark important

Swipe left:

- edit / more options

More menu:

- edit
- change date
- change type
- move to another episode
- show original note
- include in summary
- exclude from summary
- archive / hide

Swipe must never be the only way to access an action.

## Filters

V0 filters:

- all
- treatment
- symptoms
- side effects
- functioning
- questions
- context
- safety-relevant

## Anchors

Important timeline anchors:

- starting point
- treatment change
- dose change
- appointment
- side-effect onset
- side-effect resolution
- therapy start/stop
- major context/life event
- safety-relevant note

## Visual direction

The timeline should feel like:

- calm private care timeline
- practical memory
- low-friction review surface

It should not feel like:

- social feed
- medical chart cosplay
- spreadsheet
- mood dashboard
- productivity timeline
