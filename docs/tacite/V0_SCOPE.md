# Tacite V0 scope

## V0 must include

- Tacite product name
- practical, grounded copy
- English, French, Italian, and Russian UI support
- no real name required
- private profile
- no mandatory email as long-term product direction
- optional AI setting
- AI off by default
- onboarding by purpose
- timeline beginning choice
- skippable quick starting snapshot
- episode creation
- one-tap capture
- AI-off structured quick cards
- raw note preservation
- structured timeline events
- basic event types
- chronological timeline/feed as primary product object
- newest-first daily mode
- oldest-first review/story mode
- compact timeline cards
- expandable details
- correction of date/type/episode links
- questions for clinician
- summary / summary so far from selected range
- text export of summary
- clear medical and safety boundary

## V0 must exclude

- smartwatch integration
- live clinician sharing
- full calendar sync
- medication reminders
- diagnosis tools
- treatment recommendations
- complex analytics
- social or collaboration features
- large AI chat interface
- messenger UI
- swipe/card-deck confirmation
- forced daily logging
- streaks or overdue counters

## V0 success test

Tacite must be clearly better than Notes.

It must be:

- faster than Notes for recording something messy
- more structured than Notes for remembering what changed
- more useful than Notes before an appointment
- safe without giving medical advice
- valuable when AI is disabled
- low-friction enough for a tired, anxious, depressed, or overwhelmed user
- centered on a chronological story, not a pile of notes

## Current prototype status

The current app proves:

- Flutter app boots
- localization works
- FastAPI backend works
- PostgreSQL works
- auth works
- raw notes can be stored
- timeline events can be stored

The current app does not yet prove:

- good product UX
- AI-off structured capture
- onboarding by purpose
- starting snapshot
- range-based summary
- visual timeline
- non-Notes differentiation
