# Tacite summary model

## Product role

The summary is the main payoff after the timeline.

Use feature names:

- Summary
- Summary so far
- Appointment summary
- Summary to bring to an appointment

Avoid naming the generic feature after a clinician role. Use Summary, Summary so far, Appointment summary, or Summary to bring to an appointment.

## Summary ranges

A summary is generated from a selected timeline range.

Range options:

- since last appointment
- since treatment change
- since dose change
- last 2 weeks
- last month
- custom range

## Summary sections

Possible sections:

1. Why I am bringing this up / what I want help with
2. Current treatment or situation
3. What changed
4. Why it changed
5. Starting point
6. What happened after
7. Side effects
8. Functioning
9. Context
10. Safety-relevant notes, if any
11. Questions for the specialist
12. Optional raw notes appendix

## Language rules

Use:

- You recorded...
- You noted...
- You described...
- The timeline shows...
- You may want to discuss...

Avoid:

- This caused...
- You have...
- You should...
- This treatment failed...
- You need...

## AI-off summary

AI-off summaries must still work.

Template summary example:

Since [date], you recorded:

- Treatment/situation:
- Main changes:
- Symptoms:
- Side effects:
- Functioning:
- Context:
- Questions:

The user can edit before export.

## AI-on summary

AI can improve wording, grouping, and clarity.

AI must not:

- diagnose
- recommend treatment
- infer causality
- invent facts
- omit uncertainty
- hide raw notes

## Export

V0 export:

- copy text
- export text file if easy

Later:

- PDF export
- optional raw notes appendix
