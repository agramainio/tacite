# Tacite documentation

Tacite is a private mental-health preparation and treatment-change memory app.

This folder is the product source of truth.

Current rule:

The current Flutter/FastAPI app is a technical spike proving backend, auth, localization, and timeline persistence. It is not yet the product direction.

The product direction is:

- raw notes are input
- chronological timeline is the primary product surface
- range-based summary is the main payoff
- AI is optional and off by default
- AI-off mode must be useful through structured quick capture
- no diagnosis
- no medical advice
- no treatment recommendations
- no mandatory real name
- no mandatory email as a long-term product goal
- English, French, Italian, and Russian from V0

Core copy direction:

Record what changed. Prepare what to say.
